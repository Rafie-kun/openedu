## International transfers

Every row above that names a specific recipient (Gemini, Frankfurter, hosting/database provider) can
process data outside the country a given student is in. No lawful transfer mechanism (SCCs, adequacy
decision, or equivalent) is documented anywhere in this repository, because the operator's jurisdiction and
the providers' processing locations are not yet fixed. This is a launch blocker, not an oversight to silently
accept — see `docs/legal-review-checklist.md`.

## What is explicitly not done with this data

- No targeted advertising using any of the above.
- No sale of personal or academic data to a third party.
- No use of academic profile, grades, nationality, or financial need band for a purpose other than the
  eligibility and planning features the student is actively using.
- No AI processing of a student's documents — none are uploaded or sent anywhere, because upload isn't
  built yet (Milestone 8).
